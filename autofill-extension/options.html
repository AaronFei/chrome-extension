Auto Login

要新增網站：開啟那個網站的登入頁，點瀏覽器右上角的 extension 圖示 →「設定這個網站」。
右上角的開關可以隨時把單一網站關掉（設定會留著，隨時再打開）。

本機加密（passkey）

開啟後，帳密、PAT、同步金鑰在這台電腦的硬碟上只剩密文， 金鑰要靠 Touch ID / Windows Hello 才拿得到 —— 就算整個 Chrome profile 被木馬打包帶走也解不開。
代價：每次開 Chrome 後，第一次用到時要按一次（遇到要登入的網站會出現「解鎖並登入」提示）。 解鎖期間資料在記憶體裡，擋不住正在執行的木馬。

裝置金鑰（發卡）

每台機器自己產一把匯不出去的私鑰。舊機器把憑證用新機器的公鑰封起來丟進同一個 gist， 只有那台的私鑰解得開 —— 所以公鑰和 gist 網址都可以隨便貼，全程不用搬任何秘密。

備份與轉移（加密檔）

匯出一個加密檔 + 一組一次性轉移碼。檔案走 AirDrop / USB / 雲端都行， 碼你自己打過去 —— 兩條路徑分開，任一條外洩都解不開。
沒辦法做成「只有 extension 解得開」：程式碼就躺在你硬碟上，寫死的密鑰對拿得到檔案的人等於公開。 所以鑰匙跟著你走，不跟著程式碼走。
轉移碼只顯示這一次 —— 現在就複製走，關掉這頁就沒了（沒有備份，弄丟只能重匯）。
關於密碼保存：帳密存在 chrome.storage.local，只有這個 extension 讀得到，網頁讀不到， 也不會同步到雲端。但它沒有加密——能拿到你電腦帳號的人就能讀到。 請不要用在網銀、主要 email 這類高風險帳號。
